# MCP 安全工具

## 设计目的

项目的 `tools/` 目录把本机已经安装的安全工具封装为一个 stdio MCP 服务。MCP 层只负责参数校验、
安全默认值、命令执行、超时和结构化返回，不下载、复制或内嵌第三方工具本体。

安装红队 Preset 后，最新版 DSH 的原生 MCP 客户端会启动随包发布的服务，并以 `redteam-tools` 作为
服务器名称注册工具。MCP 服务即使找不到某个第三方命令也可以启动；状态工具会报告不可用原因。

## 工具矩阵

| 集成       | 本机依赖           | MCP 工具                                                                               | 最低模式          |
| ---------- | ------------------ | -------------------------------------------------------------------------------------- | ----------------- |
| Nmap       | `nmap`             | `nmap_status`、`nmap_scan`                                                             | 主动扫描          |
| Burp Suite | Burp 代理与 `curl` | `burp_status`、`burp_proxy_request`                                                    | 主动扫描          |
| Metasploit | `msfconsole`       | `metasploit_status`、`metasploit_search`、`metasploit_module_info`、`metasploit_check` | 信息收集/漏洞验证 |
| Nuclei     | `nuclei`           | `nuclei_status`、`nuclei_scan`                                                         | 主动扫描          |

状态检查和 Metasploit 模块搜索/说明不连接目标，最低为信息收集；`metasploit_check` 最低为漏洞验证。

## 本机安装要求

DSH 进程必须能在自己的 `PATH` 中找到对应命令。自定义位置可通过环境变量指定：

| 环境变量                | 默认值       | 用途                          |
| ----------------------- | ------------ | ----------------------------- |
| `PRISM_NMAP_BIN`        | `nmap`       | Nmap 可执行文件               |
| `PRISM_NUCLEI_BIN`      | `nuclei`     | Nuclei 可执行文件             |
| `PRISM_MSFCONSOLE_BIN`  | `msfconsole` | Metasploit 控制台             |
| `PRISM_CURL_BIN`        | `curl`       | Burp 代理请求使用的 curl      |
| `PRISM_BURP_PROXY_HOST` | `127.0.0.1`  | Burp 代理地址，只允许回环地址 |
| `PRISM_BURP_PROXY_PORT` | `8080`       | Burp 代理端口                 |

环境变量必须在启动 `dsh web` 前设置，确保 MCP 子进程能够继承。

## 各工具的限制

### Nmap

- 只接受规范化的 IP、CIDR 或域名。
- 使用 TCP connect 扫描、`T3`、最多两次重试，只返回开放端口。
- 默认扫描常见 100 端口；可指定受校验的端口列表或范围。
- 单次最多 16 个目标，超时范围 30–600 秒。
- `service` 档只增加轻量服务版本识别。

### Nuclei

- 只接受 HTTP(S) URL，单次最多 16 个。
- 默认严重度为 medium、high、critical。
- 并发固定为 5，批量大小 10，速率上限可在 1–50 之间设置。
- 禁用 Interactsh、未签名模板、DoS 和 fuzz 标签，并关闭自动更新检查。

### Burp Suite

- 适配器不是 Burp 扩展，也不控制 Burp GUI。
- 它使用本机 `curl` 经回环地址上的 Burp 代理发送 GET、HEAD 或 OPTIONS 请求。
- Burp 代理必须监听 `localhost`、`127.0.0.1` 或 `::1`。
- 单次请求超时范围 5–60 秒；默认验证 TLS，仅在明确选择时允许跳过验证。

### Metasploit

- `search` 和 `info` 只查询本机模块库，不连接目标。
- 验证只执行模块的 `check` 动作。
- 适配器不会调用 `run` 或 `exploit`。
- 目标、模块名、端口、SSL 和 `TARGETURI` 都经过格式校验。

## 执行前条件

所有连接目标的 MCP 工具都要求 `authorizationConfirmed: true`，但该参数不是唯一授权依据。Host 还会
依次检查：

1. 工具是否已经勾选并确认。
2. 每个目标是否处于已确认范围内。
3. 当前四档模式是否达到工具要求。
4. DSH 原生沙箱、审批和其他策略是否允许。

任何目标不在范围内都会直接拒绝，不能通过“全部允许”或逐步审批绕过。

## 手动启动 MCP 服务

构建后可以独立启动，用于协议调试：

```bash
pnpm build
node tools/dist/server.js
```

安装 npm 包后也可以使用：

```bash
dsh-redteam-mcp
```

正常使用红队 Preset 时不需要手动启动；Preset 已把随包服务交给 DSH MCP 客户端管理。

## “添加工具”与真实接入

看板中的“添加工具”通过 DSH 原生 MCP 客户端建立连接并发现工具，连接成功后显示工具数量；失败不会创建成功卡片。支持 Streamable HTTP 和 STDIO，不支持旧版 SSE。HTTP 地址不能包含账号密码、查询参数或片段；STDIO 仅接受可执行文件绝对路径，不解析 Shell 命令或参数。需要认证头或启动参数的服务应在 DSH profile 中配置。

添加成功后，看板向当前 DSH 会话提交权限评估请求，复用该会话的模型、队列和日志。AI 调用 `redteam_mcp_permissions` 读取工具说明与参数 Schema，逐项建议信息收集、主动扫描、漏洞验证、全部允许或禁止使用，并给出中文理由和目标参数。工具元数据是不可信数据，评估过程不执行待评估工具。

建议显示在工具卡片中。先点击“确认 AI 权限建议”，再勾选工具并点击“确认选择”才会启用；建议本身不会授权。标为禁止使用的子工具始终拒绝，即使同一连接内其他工具已经启用。评估请求失败时可点击“AI 重新评估权限”。

当前支持从顶层字符串或字符串数组参数提取主机或 HTTP(S) URL，并继续使用既有目标范围与等级检查。无目标的权限仅用于本机离线状态或说明查询。任意命令、载荷、凭据攻击、破坏性操作，以及目标隐藏在自由文本、嵌套结构或多个参数中的工具，应建议禁止使用；不支持的目标格式不能自动放行。AI 建议需要用户核对其用途与目标参数。

建议绑定确切的工具描述和参数 Schema。工具定义改变后旧映射失效；重新评估会撤销该连接的旧启用选择，需再次确认。未评估、未确认、无有效映射或越界调用均拒绝；当前模式低于建议等级时逐步审批。DSH 原生沙箱和审批继续生效。

连接定义按会话保存于 `.dsh-redteam/sessions/`，重新打开会话时由 DSH 恢复连接；服务离线时显示连接失败，可提交相同配置重试。每个会话最多保存 16 个连接。切换会话不会丢失已保存的连接定义，卸载插件时关闭连接且保留用户数据。
