# 安全模型

## 四层执行条件

本地安全工具调用必须同时通过四层条件：

```text
工具已勾选并确认
        ↓
目标位于已确认范围
        ↓
当前模式满足要求，或逐步审批
        ↓
DSH 原生沙箱、审批与其他策略
```

其中目标范围是硬边界：不在范围内时直接拒绝，不进入审批流程。“全部允许”只提高执行权限等级，
不会扩大目标范围。

## 工具确认

看板勾选工具后只形成待确认选择；用户必须点击“确认选择”，Host 保存成功后才允许调用。未确认工具
直接拒绝。这个检查在浏览器状态之外执行，不能通过改前端 DOM 绕过。

## 模式与审批

权限等级从低到高依次为信息收集、主动扫描、漏洞验证、全部允许。

- 当前等级等于或高于工具要求：棱镜策略返回继续执行。
- 当前等级低于工具要求：该次调用请求审批；下一次调用仍会重新请求。
- 工具没有定义权限规则：所有 MCP 命名空间均直接拒绝。`redteam-tools` 使用内置权限映射；扩展服务器仅使用用户已确认、且与当前工具描述和参数 Schema 一致的 AI 建议。同名工具不能继承其他服务器的权限。

“继续执行”只表示通过棱镜这一层，DSH 后续策略仍然有效。

## 扩展 MCP 权限建议

添加工具后由当前 DSH Agent 读取工具元数据并提交建议，不建立第二套模型客户端或 Agent。AI 只能写入待确认建议，不能自行确认或启用。用户在看板确认确切版本的建议后，仍需勾选并确认工具选择。待确认、禁止使用和元数据已变化的工具默认拒绝。

网络工具必须使用有效的顶层字符串或字符串数组目标参数，并逐个通过已确认范围检查。缺失、混合类型、空数组和越界目标均拒绝。只有明确的离线状态或说明查询可建议无目标的信息收集权限；不能可靠描述目标或影响的工具建议禁止使用。工具元数据不得被当成指令，评估不调用待评估工具进行试探。

## 目标范围

- 范围来源于当前项目资产图中的勾选节点。
- 域名“全部子域名”只允许精确域名和其下级域名。
- IP“仅当前 IP”只记录资产，不授权端口访问；“全部端口”才允许对该 IP 执行扫描和访问，且不会授权其他 IP。单个 HTTP 服务可使用 URL 范围限制端口和路径。
- CIDR 网段只按合法 IPv4 网段检查地址归属。
- URL 按协议、主机、端口和路径前缀检查；授权 `/v1` 不会授权 `/admin`。
- URL 范围不会自动授权 Nmap 主机扫描。
- 目标缺失、格式非法或携带 URL 用户名/密码时拒绝。

当前最多接受 256 条目标范围规则。

## 工作区路径范围

- 当前会话解析出的 workspace root 是本地评估的唯一授权根。
- 扫描子路径同时检查词法路径和真实路径。
- 目录遍历不跟随符号链接。
- 工具参数中的 `path`、`file_path`、`cwd`、`workdir`、`directory`、`root` 越界时拒绝。
- 未拒绝的调用继续交给 DSH 下游策略。

范围守卫不能解析任意 Shell 语法，也不是操作系统沙箱，因此不能关闭 DSH 原生 sandbox/approval。

## 数据最小化

- 不复制 DSH 聊天、Prompt、Agent 状态或普通工具成功结果正文到知识库。
- Authorization、Cookie、密码、Token、URL 凭证等证据保存前替换为 `[redacted]`。
- 单条证据和 Finding 复核理由最多 512 字符。
- 每条 Finding 最多保留 100 次状态变化。
- 扫描、资产图、知识条目、检索结果和报告均有数量与长度上限。
- `.dsh-redteam`、`.prism` 和凭证属于用户数据，不进入 npm 包，也不由卸载自动删除。

## 知识库边界

- 版本化 JSON 是权威事实源，SQLite FTS5 只是可重建索引。
- 知识根使用私有 marker、原子写入、短时写锁和符号链接检查。
- 项目事件只有逐条满足复用、权威性和状态条件后才能晋升长期知识。
- Graphiti/RAGFlow 只接收有界、脱敏投影；失败不会影响本地事实写入。
- 外部服务默认只允许回环地址；远程连接必须是 HTTPS 并显式开启。
- Token 只从指定环境变量读取，不进入状态、错误或报告。

## 明确禁止

当前实现不提供或不允许：

- 未授权目标测试或自动扩大范围。
- 拒绝服务、破坏性写入或影响第三方的动作。
- 暴力破解、凭据攻击、持久化或数据破坏。
- 生成或执行攻击载荷、获取 Shell/WebShell。
- 把规则命中直接描述成已确认漏洞。
- 将推断关系或外部派生事实覆盖为项目权威状态。
