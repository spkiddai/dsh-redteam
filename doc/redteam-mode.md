# 红队模式

## 模式定位

“红队模式”是随插件安装的 DSH Agent Preset。它复用 DSH 的模型路由、会话、工作区、对话、沙箱、
审批、文件系统和 MCP 客户端，只增加红队 Persona、领域工具、执行策略和棱镜看板。

插件不会创建第二套 Web 应用。普通、极简、创造等其他 Preset 不显示棱镜看板，也不会获得
`redteam_*` 工具。

## 看板结构

看板包含四个一级模块：

| 模块     | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| 项目状态 | 项目概览、模型情况、信息收集、目标范围、漏洞扫描、漏洞验证、会话 |
| 资产情况 | 资产分类统计与关系图                                             |
| 漏洞汇总 | 漏洞总数、严重度统计和 Finding 详情                              |
| 工具集成 | 可用工具、确认选择、添加工具和独立的执行详情                     |

登录后只显示棱镜工作台。顶部提供项目目录、会话切换和退出登录，不再提供原 DSH 侧栏或收起入口。

## 模型情况

“模型情况”读取当前会话可路由的模型列表。选择新模型后通过 DSH 会话接口切换，不在插件中保存 API
Key。统计项只保留：

- 输入 Token
- 输出 Token
- 缓存命中率
- 费用消耗

费用无法从当前模型用量中取得时显示 `—`。项目不再把对话轮次作为用量指标。

## 四档执行权限

顶部的四档模式不是展示标签，而是本地安全工具的执行权限等级：

1. 信息收集
2. 主动扫描
3. 漏洞验证
4. 全部允许

工具要求的等级不高于当前模式时，棱镜策略允许它继续进入 DSH 后续策略；要求高于当前模式时，每次
调用都返回一次审批请求。“全部允许”需要额外确认，但仍不能访问未勾选目标，也不能绕过 DSH 沙箱。

详细判定顺序见 [安全模型](security-model.md)。

## 目标范围

范围只能从当前项目的资产图中选择。单个域名、IP、URL、网段可以独立授权；域名可选择包含全部子
域名。IP 的“仅当前 IP”仅记录资产，不授权端口访问；选择“当前 IP 的全部端口”后才允许端口扫描或访问。只授权某个 HTTP 服务时应选择包含端口和路径的 URL 资产。

范围变更通过浏览器到 Host 的 RPC 提交，Host 会重新校验数据结构、资产类型和数量后保存到当前
会话。范围不是 Prompt 文本约定，而是工具调用前的服务端硬限制。

## 工具集成

内置卡片为 Nmap、Burp Suite、Metasploit 和 Nuclei。勾选卡片后必须点击“确认选择”，成功后“已开启”
数量才会更新。单纯勾选不会改变服务端许可。

“添加工具”通过 DSH 原生 MCP 客户端连接服务并发现工具，支持 Streamable HTTP 和 STDIO。卡片显示连接状态和发现数量。添加成功后由当前会话的 AI 给出逐项权限等级、目标参数和理由；用户确认建议后才可勾选启用。未评估、未确认和禁止使用的子工具不可执行，连接失败不会显示成功。连接定义按会话持久化；认证和启动参数配置见 [MCP 安全工具](mcp-tools.md)。

“执行详情”位于工具集成大框下方的独立卡片中，展示当前会话最近的工具名称、状态和脱敏摘要。

## 会话行为

- 工作台只创建 redteam 会话，不提供旧模式切换。
- 工作区来自当前会话的 sandbox policy；可通过高级配置固定工作区。
- 每个会话拥有自己的执行模式、已启用工具和测试范围，确认后以私有权限原子保存于 `.dsh-redteam/sessions/`，服务重启后恢复；损坏配置会报错并阻止执行。
- 切换会话后，旧会话尚未完成的权限更新不会改变当前会话的显示。
- Finding 状态变更成功后，看板更新同一评估内的对应条目；失败或其他评估的结果不会覆盖当前条目。
- 切入红队模式时注册工具、Prompt 和范围监听器；切出时同步撤销。
- 客户端插件随 Web profile 启动加载，但只在当前会话的 Preset 为 `redteam` 时渲染看板。

## 当前不提供的页面

当前版本暂不提供代码审计、横向移动和权限维持三个看板页面。后端保留的 `redteam_scan` 是工作区内
确定性的被动规则扫描能力，不代表看板恢复了“代码审计”流程，也不会执行目标代码。
