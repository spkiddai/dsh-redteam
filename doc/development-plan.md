# 版本状态与计划

## 当前版本：1.4.0

当前交付范围包括：

- 单 npm 包、单 Cordis 插件入口和原生红队 Agent Preset。
- 项目状态、资产情况、漏洞汇总、工具集成四个看板模块。
- 信息收集、主动扫描、漏洞验证、全部允许四档执行权限。
- 已确认目标范围硬限制，以及工具勾选后的“确认选择”流程。
- Nmap、Burp Suite、Metasploit、Nuclei 本地 MCP 适配器。
- 公开来源资产图、有界广度优先扩展和多格式导出。
- 工作区内确定性被动规则扫描与 Finding 状态工作流。
- 本地项目记忆、长期知识、FTS5 检索与可选 Graphiti/RAGFlow。
- HTML、Word、Markdown、JSON、XML、SARIF 报告。
- DeepSeek Harness `0.2.1-rc.2` 最新版单一兼容目标。

代码审计、横向移动和权限维持看板页面当前暂不提供。后端被动扫描工具继续作为领域能力存在，但不在
界面中恢复这些旧工作流。

## 下一阶段优先级

### 工具接入闭环

- 已完成看板到 DSH 原生 MCP 客户端的连接、发现和会话恢复；继续补充认证和带参数 STDIO 配置。
- 已支持 AI 提出逐项能力级别、用户确认及顶层字符串/字符串数组目标提取；继续扩展可审查的复杂参数映射。
- 增加删除、编辑、重连、持久化和健康检查。
- 未建立权限映射前继续默认拒绝，而不是自动放行。

### 任务与证据体验

- 强化扫描计划、执行进度、取消和失败重试。
- 把执行详情与 Finding 证据建立可追溯关联。
- 改进资产较多时的范围筛选、分页和批量确认。
- 为报告增加授权范围、工具版本、模式和审批摘要。

### 检测能力

- 为 JavaScript/TypeScript、Python、Go、Rust 等语言引入可选 AST 或语义检测器。
- 增加锁文件解析和供应链数据源，同时保持网络访问显式可控。
- 扩充规则测试样本，并保持 Finding ID 与版本迁移稳定。

## 迭代原则

- 只适配发布时最新版 DSH，不维护旧版运行时分支。
- DeepSeek Harness 始终是唯一 Agent、会话、MCP、沙箱和审批核心。
- 任何测试能力必须先实现目标范围和权限映射，再开放执行入口。
- 默认低影响、可取消、有资源上限，并保留可复核证据。
- 不加入拒绝服务、破坏性写入、持久化、凭据攻击或影响第三方的能力。
- 用户数据和凭证不进入发布包，也不因升级或卸载自动删除。
