# 使用指南

## 标准流程

一次红队任务建议按以下顺序进行：

1. 登录棱镜，点击顶部“打开项目目录”，选择授权项目。
2. 切换到“红队模式”，创建或读取项目状态。
3. 使用“信息收集”录入组织、域名、IP、URL 等种子并构建资产图。
4. 在“目标范围”中勾选允许测试的资产，并点击确认范围。
5. 在“工具集成”中勾选需要使用的工具，再点击“确认选择”。
6. 根据任务授权选择信息收集、主动扫描、漏洞验证或全部允许模式。
7. 运行漏洞扫描；存在已确认 Finding 时，再进行非破坏性漏洞验证。
8. 在“资产情况”“漏洞汇总”和“执行详情”中复核结果并导出报告。

## 项目状态

“项目状态”是主要工作区，包含：

- 项目概览：项目名称、资产与事件进度、结果导出。
- 模型情况：切换当前可用模型，并显示输入 Token、输出 Token、缓存命中率和费用消耗。
- 信息收集：选择资产类型并启动公开信息测绘。
- 目标范围：确认本次允许测试的资产边界。
- 漏洞扫描：根据已确认范围内的资产类型展示适用检查类别。
- 漏洞验证：只对状态为 `confirmed` 的漏洞显示验证入口；没有可验证项时显示“暂无可验证漏洞”。
- 当前会话：显示对话历史和消息输入框。

## 信息收集与资产图

信息收集只保留域名、IP、端口和服务四个采集维度。插件通过 DSH 提供的公开 Web 搜索能力，以有界
广度优先方式扩展资产；每条关系都必须保存 HTTP(S) 来源、观察时间和可信度。端口与服务信息只能
来自公开资料或当前项目已有证据，信息收集阶段不会主动执行端口扫描。

信息收集阶段不登录目标、不使用凭据、不扫描端口、不爆破子域，也不执行漏洞探测。资产关系是带来源
的观察，不应把推断直接当作已确认事实。

“资产情况”的资产概览同样只显示域名、IP、端口和服务四项：域名合并一级域名与子域名，IP 合并单个
IP 与网段，端口统计公开端口入口，服务汇总已识别产品、技术和基础设施服务。下方显示可缩放关系图。
节点颜色含义为：

- 绿色：当前没有漏洞记录。
- 黄色：尚未完成测试。
- 红色：存在漏洞记录。

## 确认目标范围

只有资产图中已经发现的节点可以加入目标范围。界面最多预览前 8 个候选节点，支持：

- 单个资产：只授权当前域名、IP、URL 或网段。
- 全部子域名：仅适用于域名，授权该域名及其子域名。
- 仅当前 IP：只记录该资产，不授权端口访问；要测试单个 HTTP 服务，可选择包含端口和路径的 URL。
- 全部端口：仅适用于 IP，允许扫描或访问该 IP 的端口。

勾选后必须点击范围确认按钮，服务端收到并验证后才生效。未勾选目标始终被拒绝，即使当前模式是
“全部允许”。URL 范围还会限制协议、主机和路径；授权一个 URL 不等于授权整个主机。

## 选择执行模式

四档模式同时代表本次任务的执行权限等级：

| 模式     | 等级 | 典型用途                         |
| -------- | ---- | -------------------------------- |
| 信息收集 | 1    | 状态检查、公开信息和本地模块查询 |
| 主动扫描 | 2    | Nmap、Nuclei、Burp 受限请求      |
| 漏洞验证 | 3    | Metasploit `check` 等受控验证    |
| 全部允许 | 4    | 放开当前已定义能力的最高入口     |

当前模式等于或高于工具要求时，插件权限层不再追加逐步审批；低于工具要求时，每一次调用都会请求审批。
无论选择哪种模式，调用仍继续经过 DSH 的原生沙箱和策略。

## 启用工具

工具卡片中的勾选只是待确认选择。操作顺序是：

1. 勾选工具。
2. 检查“已选择”数量。
3. 点击“确认选择”。
4. 看到“已开启”数量更新后才表示服务端许可已生效。

没有点击“确认选择”时，工具调用会被服务端拒绝。工具启用、执行模式和目标范围三个条件必须同时
满足。详细规则见 [安全模型](security-model.md)。

## 漏洞扫描与验证

“漏洞扫描”只使用已确认范围内的资产，并按 Web、Redis、网络、组件或云资产展示适用类别。候选项
默认是 `candidate`；证据充分后才可更新为 `confirmed`。

“漏洞验证”只显示 `confirmed` Finding。当前界面的验证流程复核已有代码、配置、日志和资产证据，
说明前置条件与影响，不生成或执行攻击载荷，不获取 Shell/WebShell，不读取凭据，不修改目标数据。

本地 MCP 工具可以执行受限网络检查，但仍必须满足工具确认、权限等级、目标范围和 DSH 原生策略。

## 查看与导出结果

- “资产情况”用于查看资产统计与关系图。
- “漏洞汇总”用于查看严重度统计和 Finding 详情。
- “执行详情”是工具集成下方的独立区域，显示当前会话最近的工具状态和脱敏结果。
- 项目概览可导出资产数据、漏洞详情或项目报告。

资产图支持 HTML、Mermaid Markdown、GraphML 和 JSON；评估报告支持 HTML、Word、Markdown、JSON、
XML 和 SARIF。界面提供的快捷导出主要使用 Word、Markdown 和 HTML。

## 会话边界

- 执行模式、工具选择和目标范围按当前会话维护。
- 切换会话时，界面重新读取服务端策略；新增 MCP 工具卡片属于当前前端会话状态。
- 项目事实、资产图、评估和报告写入工作区 `.dsh-redteam/`，不会依赖聊天历史作为权威数据。

## 添加 MCP 工具并获取 AI 权限建议

1. 在“工具集成”填写名称、接口地址和协议，点击“添加工具”。
2. 连接成功后，当前会话的 AI 自动读取工具说明和参数，给出逐项权限等级、中文理由及目标参数，不执行待评估工具。
3. 在卡片核对建议并点击“确认 AI 权限建议”，再勾选该连接并点击“确认选择”。禁止使用的子工具不会因此放行。
4. 执行时仍按已确认目标范围和当前操作等级检查，超出范围拒绝，等级不足时逐步审批。
5. AI 评估失败时点击“AI 重新评估权限”。重新评估后需要再次确认；工具定义变化会使旧权限失效。
